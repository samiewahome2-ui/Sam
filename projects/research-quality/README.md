# Research evidence register

A template for translating research findings into traceable, decision-ready statements.

1. Define population, comparator, time window and limitations.
2. Link each claim to a versioned source or result.
3. Classify evidence as verified, partial or unsupported.
4. Separate observed results from recommendations.
5. Hold consequential decisions when material evidence is missing.

The [CSV register](evidence-register.csv) contains fictional examples. A reviewer should independently confirm the underlying source before changing a claim to verified.
